How it works

Runout forecast

Burn rate and the exact time each 5-hour and weekly window runs out, for Claude Code and Codex, side by side.

Subagent guard

A hook that blocks new subagents when you're on pace to run out before the reset. Override any time.

Burn report (Pro)

Tokens by day, project, model and session, plus how much your subagents really cost. One shareable Markdown file.

Trim advisor (Pro)

What every session loads before you type (often 100k+ tokens) and the specific files, MCP servers and skills to cut.

Install in 30 seconds

npm install -g limitcast
limitcast install --guard   # wraps your status line, adds the guard, backs up settings.json
limitcast doctor

Requires Node 20+, macOS or Linux. limitcast uninstall restores your original settings.

FAQ

Does it send my code or prompts anywhere?

No. limitcast reads the limit readings Claude Code passes to your status line and the logs Claude Code and Codex already keep on your disk. Nothing leaves your machine, and license keys are checked offline.

Does it use my Claude login?

No. It never touches your subscription credentials, so it can't put your account at risk.

I use extra usage past my limit. Will the guard block me?

No. Once a window is used up, limitcast steps aside and leaves it to Claude Code. The guard only acts while you're heading toward a limit.

What if I have two Claude accounts?

Each session is forecast from its own readings, so parallel accounts never mix.
